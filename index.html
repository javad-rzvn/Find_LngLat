جستجو محل و یافتن طول و عرض جغرافیایی و اطلاعات آب و هوا

در این صفحه می‌توانید مختصات طول و عرض جغرافیایی هر نقطه دلخواه را کپی و پیست کنید.
نحوه استفاده: با استفاده از جعبه جستجو مکان مورد نظر را جستجو کرده یا نقشه را جابجا کنید و سپس روی نقطه‌ای که می‌خواهید مختصات آن را بگیرید کلیک نمایید. سپس می‌توانید مختصات را در فایل‌هایی مانند CSV بچسبانید و استفاده کنید.
نقشه‌های مورد استفاده: OpenStreetMap (© مشارکت‌کنندگان OpenStreetMap)، API مورد استفاده: از OpenStreetMap Nominatim API استفاده شده است.
